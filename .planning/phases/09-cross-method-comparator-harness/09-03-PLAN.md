<objective>
Build the shared-input source for the comparator: a seeded θ grid spanning the
colocalization regimes (coloc / random / exclusion) that reuses the frozen
`sample_prior` → `simulate_pair` → `build_mci` chain to emit a reproducible
`Vector{MultiChannelImage}`, each carrying its simulator ground-truth regime label
(D-02). The same entry point must also accept a caller-supplied vector of images
(D-03) so the Phase-8 external corpus can be fed later without redesign.

Purpose: The ground-truth regime label is the anchor that lets the table show
*when* a classical estimator is wrong. Keeping the harness input-agnostic is what
makes Phase 9 reusable by Phase 16 without a rewrite.
Output: `spike/comparator/inputs.jl` exporting `build_shared_inputs`.
</objective>
