**Two bindings that are easy to lose.**

- **R-2 / Pitfall 7: the SAMPLED object is the GAUSSIAN field.** ρ is its deterministic monotone
  transform. This file therefore returns the Gaussian field `z` alongside the ρ field, and `z` is what
  the θ rows are built from downstream (12-09). In ρ space the elementwise `ghat` clamp puts a measured
  **6.79 % atom mass on every region**; in Gaussian space there are no atoms at all. Do not quietly
  drop `z` from the return value because "the deliverable is a Δρ map" — the deliverable is derived
  from `z`, and 12-18's clean SBC arm has no other input.
- **Generative order (the `p11_generate.jl:20-33` discipline, transposed).** `r1` — the induced lag-1
  correlation, D-08's inferred correlation length — is drawn **FIRST**, and the field is drawn
  **conditional on it**. Phase 11's header records why this order is the entire point of a file like
  this one: the wrong order produces a null that looks exactly like "below the summary's resolution"

**This file does not know about θ vectors, DCT rows or networks.** It draws fields and nuisances. The
72-row θ assembly lives in `spike/data/p12_generate.jl` (12-09), which is the only file that includes
