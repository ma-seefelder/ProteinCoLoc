<objective>
Turn D-08's hedge — *"expect this column may prove unidentifiable; report it as such if so"* — into a
pre-registered measurement, using a probe strong enough that a null means something.

Purpose: S-1 is explicit that prose is not enough here, and Phase 11 is the reason. Its λ marginals widened
**4.84–9.05×** and were read as the conditioning being "alive and used" when **12.0 = LAMBDA_MAX/LAMBDA_MIN
is the prior-echo ceiling** reachable by a network that ignores the image entirely. The correlation length is
exposed to the identical misreading: a wide, responsive posterior on r₁ is trivially consistent with the flow
reproducing its prior. Phase 11 also built the instrument that settles it, and Pitfall 3 adds the one feature
that makes it fair — Moran's I, the natural near-sufficient statistic for a second-order quantity.
Output: `run_p12_ell_ridge.jl` and its reported artifact. **This gates nothing.**
</objective>

**Two differences from the Phase-11 template, both deliberate.**
1. **There is no row to exclude.** Phase 11's probe excluded row 129 because λ was a *conditioning input*
   and admitting it would have measured prior echo. D-08 **infers** the correlation length rather than
   conditioning on it, so there is no such row — and the header must say so, because "row 129 is excluded and
   this is the whole point" is the analog's most quotable line and copying it here would be wrong.
2. **A raw-rows ridge is a weak probe for a second-order quantity, so it is not the only arm.** r₁ is a
   property of the *spatial autocorrelation* of the 64 continuous rows, not of their levels. A linear map on
   raw levels can barely see it. Pitfall 3 therefore requires the empirical **lag-1 spatial autocorrelation
   (Moran's I)** of the 64 continuous rows as an engineered predictor, and requires **both** arms to be
   reported: raw-rows-only, and raw rows + Moran's I. Reporting only the weak arm would let an
   implementation limitation masquerade as a physical null — which is the same error class as Pitfall 3
   itself, run in the opposite direction.

**This plan runs regardless of the 12-11 verdict.** On a Stage-1 DESCOPE the D-08 identifiability answer is
still a phase deliverable and still shapes how named limit #4 (vacuous nuisance columns) is written up. It
depends on 12-11 only to serialize pool generation under `spike/data/cache/p12/`, not on its outcome.
