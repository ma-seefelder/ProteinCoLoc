`reshape_summary(Zraw::AbstractMatrix, G::Integer = P12_G) -> Array{Float32,4}` — `Zraw` is
`(2G²) × K`, exactly what `encode_d01` produces. Returns `(G, G, 2, K)` with channel 1 the
correlation lattice and channel 2 the present-mask lattice, via
`@views out[:,:,1,:] .= reshape(Zraw[1:n, :], G, G, K)` and the mask rows into channel 2. Throw
`DimensionMismatch` when `size(Zraw,1) != 2G²`. Docstring must state that `reshape(view, G, G)`
recovers the original `patch_summary` matrix EXACTLY with **no transpose**, and must carry the
ordering warning in the `p11_architecture.jl:330-333` voice: standardize FIRST (frozen per-row `zt`,
mask rows bypassed), THEN reshape — a reshape-then-standardize ordering re-couples the mask.

`mask_regions(Zraw::AbstractMatrix, idxs; G = P12_G)` — set the continuous row and the mask row of
each named region to `0.0`, returning a copy. This is the SAME encoding `encode_d01` already produces
for a patch that falls below the ≥15-surviving-pixel floor, so "region unobserved" is expressed in
the existing vocabulary rather than a new sentinel. Also
`sample_mask_k(rng; k_set = P12_MASK_K_SET)` and
`augment_mask!(Zraw, rng; G = P12_G, k_set = P12_MASK_K_SET)` — the MCAR training-time augmentation
(Pitfall 4). Record in the comment why it exists: on the F5 mixture with `BG_FLOOR = 0.02` masked
patches are RARE in training, so a net that has essentially never seen a masked region would make
D-09's leave-region-out coverage measure out-of-distribution behaviour rather than borrowing strength.
Also state the warning sign: if leave-region-out coverage is wildly off nominal for BOTH the spatial
model and the D-10 ablation, suspect this augmentation before suspecting the prior.

`build_p12_summary_net(; G = P12_G, dstar = 128)` — the LEAN topology, written literally and
commented with the measured cost that justifies it:

```
Conv((3,3), 2  => 16, gelu; pad = SamePad())   #  G×G×2  → G×G×16
Conv((3,3), 16 => 32, gelu; pad = SamePad())   #  G×G×16 → G×G×32
Conv((1,1), 32 =>  8, gelu)                    #  G×G×32 → G×G×8    channel bottleneck
Flux.flatten                                   #  → 8G² = 512 at G=8
Dense(512, dstar)                              #  → dstar = 128
```

Comment must record: the fat alternative (`2→32→64→64`, flatten 4096, `Dense(4096,256)`) has
1 137 760 summary parameters and measured 12.5 h at D=72/50k versus 70 872 parameters and 1.8 h for
this one; the `Dense(4096,256)` alone is 92 % of the fat net's parameters. Also record the
ANTI-PATTERN explicitly: **no `GlobalMeanPool`, no `DeepSet`, no permutation-invariant pooling
anywhere in this net** — permutation-invariance over patches IS the exchangeable pooling this phase
exists to replace; a flatten-then-Dense head after the convs is the point. `Dense(8 * G^2, dstar)`
must be derived from `G`, not hard-coded to 512.

`build_p12_estimator(; G = P12_G, D = P12_D_MINISPIKE, dstar = 128, num_coupling_layers = 10,
flow_depth = 2, flow_width = 128)` — builds the summary net, then
`q = NormalisingFlow(D; num_summaries = dstar, num_coupling_layers = ..., depth = ..., width = ...)`
and returns `PosteriorEstimator(network, q)` with `q` passed POSITIONALLY as an INSTANCE. Guards in
the `architecture.jl:92-99` style: `D >= 2`, `dstar >= 1`, `G >= 2`, each throwing `ArgumentError`
naming the offending value. Docstring records the verified v0.2.1 facts: the summary network is
called directly (`_summarystatistics(estimator, Z) = estimator.summary_network(Z)`), so ANY Flux
model accepting a 4-D `Z` works; `NormalisingFlow` is dimension-generic so **no custom
`ApproximateDistribution` is needed**; and `Unet` is NOT exported by v0.2.1, so D-01's
finite-dimensional vector head is the only route the pinned library supports.

`P12_THETA_ROWS(K = P12_K_DEV)` — a `Vector{Symbol}` giving the row order exactly as in this plan's
`<context>` block, so every downstream reader indexes by name-derived position rather than by a
re-derived guess. Provide `p12_theta_index(sym; K = P12_K_DEV)` and the three convenience ranges

`length(P12_THETA_ROWS()) == P12_D_MINISPIKE` at load.
