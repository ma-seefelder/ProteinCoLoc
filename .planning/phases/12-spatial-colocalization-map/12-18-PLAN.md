<objective>
Report per-region calibration in the one space where this phase's own prior construction does not
manufacture artifacts, and apply a test to each row that matches what that row actually is.

Purpose: this project has already been burned twice by the reverse. Named limit #2 is the `ρ_true`
prior-atom artifact, and Phase 11 measured what ignoring it costs on a live net — coverage 0.723–0.767
against nominal 0.90, intervals ~40 % too narrow, attributed to the atom artifact rather than to any
calibration defect. Spike 011 established the other half: `M = 2000` point-null SBC resolves a 0.059-SD
marginal drift while a neural flow's irreducible drift on a **non-identified** parameter is 0.04–0.07 SD,
which no capacity lever removes. D-01's head raises the parameter count to `P12_D_PROD`, so it raises the
number of non-identified rows with it, and a naive per-row point-null gate would fail loudly and
uninformatively — the exact "twice-amended gate" outcome the milestone's named limits already record.
Output: two SBC arms, per-row verdicts under the right test for each row, and one reported artifact.

**WHY GAUSSIAN SPACE IS THE PRIMARY ARM, NOT A CONVENIENCE (R-2).** Under D-05's copula the *sampled*
object is the Gaussian field; the ρ field is its deterministic monotone transform through `ghat`. So the
DCT coefficients of the Gaussian field are what the prior actually draws, and in that space there are
**no atoms at all** — the clamp lives only in the read-time map. Measured atom mass in ρ space is
**6.79 % per region**, essentially identical to the current global 6.78 %, so D-05 multiplies the number
of atoms by 64 without inflating their rate. Because `ghat` is monotone and elementwise it preserves
credible intervals exactly, so nothing is lost by scoring in Gaussian space. The ρ-space arm is reported
**as well**, with randomized ranks, because the milestone's existing tables are in ρ units and a reader
needs the comparable number.

**THE TEST MUST MATCH THE ROW (Pitfall 8).** Strict point-null KS at `P12_SBC_TARGET_KS_ALPHA = 0.01`
applies to the **targets only**: the global term `c₀` and Δρ. The seven nuisances, the r₁ row, and the
high-index deviation coefficients are non-identified almost by construction, and they get the
nuisance-appropriate **equivalence test** (TOST) at `P12_SBC_TOST_DELTA = 0.10`,
`P12_SBC_TOST_ALPHA = 0.05`. `P12_SBC_M`, `P12_SBC_L` and `P12_SBC_BINS` are deliberately unchanged from
`consts.jl`: 12-01 records that the settled fix for the M = 2000 over-power finding is **the test, not the
power**. Do not reduce M to make a row pass — that is the failure mode this paragraph exists to prevent.

**DO NOT SCORE 64 INDEPENDENT MARGINALS.** D-01 chose a hierarchical head precisely so calibration stays
tractable: the SBC surface is the global term plus a **low-dimensional deviation summary**, not 64
per-region marginals. The apparatus already strained at 8 parameters with 5 vacuous.

**Functions.**

`p12_row_classes(theta_rows)` — return a NamedTuple partitioning row indices into
`(targets, nuisances, dev_low, dev_high, r1)`. `targets` = `p12_row_c0` plus the Δρ row if one is
carried. `dev_low` = the first `n_low` deviation coefficients in `p12_dct_order` (the smoothness-ordered
modes a reader should expect to be identified); `dev_high` = the rest. Declare `n_low` as a named local
constant with a one-line derivation and record it in the artifact — an unrecorded split between "expected
identified" and "expected vacuous" would let the boundary move to suit the result.

`deviation_energy(coeffs)` — the low-dimensional deviation summary D-01 asks for: the total energy in the
deviation coefficients (sum of squares over `p12_rows_dev`), plus per-band energies over a small fixed set
of DCT frequency bands. Because the DCT is orthonormal, this energy is an exact function of the sampled
coefficients and carries no transform artifact — state that, since it is the reason the summary is
legitimate for SBC while "the cell mean of the interpolated field" (rejected by D-07) is not.

`p12_sbc_ranks(bundle; M = P12_SBC_M, L = P12_SBC_L, space = :gaussian, rng)` — mirror
`sbc.jl:sbc_ranks`'s shape. For each of `M` replicates: draw θ* from the Phase-12 prior, simulate,
encode, standardize with the FROZEN transforms, reshape, draw `L` posterior samples, and rank θ* among
them per row. Two spaces:
- `:gaussian` — rank the sampled DCT coefficients and the deviation-energy summary directly. No
  randomization is needed or applied here; assert that and say why (no atoms exist in this space).
- `:rho` — map both θ* and the draws through the frozen `ghat` read path first, then rank. **Apply the
  randomized-rank recipe** for rows carrying atoms: detect atom membership by `x .== minimum(x)` /
  `x .== maximum(x)` over the replicate column, and replace those PIT values with `rand()`. Return both
  the raw and the randomized `u` vectors so a reader can see the size of the correction rather than only
  its result — Phase 11's 0.72–0.77-versus-0.90 gap is exactly this quantity and it deserves to be visible.

`p12_sbc_verdicts(ranks, classes; ...)` — apply the matched test per class:
- targets ⇒ `ExactOneSampleKSTest(u, Uniform(0,1))`, pass if `pvalue >= P12_SBC_TARGET_KS_ALPHA`
- nuisances, `r1`, `dev_high` ⇒ TOST on the rank-mean against 0.5 with half-width
  `P12_SBC_TOST_DELTA` at `P12_SBC_TOST_ALPHA`, i.e. equivalence rather than difference. Write the two
  one-sided tests explicitly rather than calling a "TOST" helper that does not exist in this repo.
- `dev_low` ⇒ report BOTH tests and mark which is the pre-registered one for that class (declare it here:
  equivalence, because even low-index deviation modes are not the phase's targets). Reporting both is the
  honest move given the class boundary is a judgment.
Return a per-row table with the row name, class, test used, statistic, p-value, and verdict. Also compute
ECE/MCE per row by reusing the project's `_bin_calibration`/`CalibrationResult` shape rather than a new
binning.

`p12_shrinkage_table(bundle, ranks)` — F3 reporting-only: `shrinkage = post_sd / prior_sd` per row with
the `vacuous` boolean off `P12_VACUOUS_SHRINKAGE_FLOOR`. This is the table that makes limit #4 (vacuous
nuisance columns) concrete for this phase, and it must include the `r1` row so it can be read against
12-13's independent ridge answer for the same parameter.
