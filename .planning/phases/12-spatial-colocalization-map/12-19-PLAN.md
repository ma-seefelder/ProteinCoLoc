Score the leave-region-out predictive comparison on genuine microscopy data, which is the only part of
SC3 that a simulation cannot supply, and state the resulting claim at exactly the strength the data
support.

Purpose: D-09 made the coverage criterion ground-truth-free precisely so it could run on real images, and
D-11 (AMENDED) settled which images. The temptation this plan exists to resist is overstating the result:
the six committed TIFFs are three channels each of **two** images, so the honest n is 2 images × ~64

independent trials would be the single most inviting overclaim in the phase — and it is the same
unit-mismatch error, one level down, that already had to be corrected once for the gate itself.

prove the sealed holdout stayed sealed.

**WHAT SC3 ACTUALLY SCORES IS SINGLE-STACK, SO n = 2 AND NO CONTROL IS NEEDED.** This needs stating
plainly because it is easy to get wrong in both directions. D-09's construction
(`12-RESEARCH.md` § "The leave-region-out predictive construction") is:

```
Z_full = encode_d01(patch_summary(mci, 8));  Z_r = mask_region(Z_full, r)
draws  = sampleposterior(est, reshape_summary(Z_r, 8); N);  rho_r = read_region(draws, r)
score  : is the OBSERVED Z_full[r] inside the predictive interval, and its log density
```

Every step operates on **one** image. There is no control image anywhere in it. So the SC3 criterion —
leave-region-out predictive coverage — is computable on each of the two specimens independently, giving
**n = 2 images, ~64 regions each**, and needing no pairing at all.

**Δρ, BY CONTRAST, IS NOT COMPUTED ON REAL DATA, AND THAT IS A NAMED LIMIT RATHER THAN AN OMISSION.**
`delta_rho(est, Zsample, Zcontrol, θzt)` means a *matched* sample-and-control pair. The two committed
specimens are `role = positive` / `truth = coloc` and `role = negative` / `truth = segregated` — a
**labelled test pair, not a matched control pair.** 12-09's simulated pair shares all seven nuisances by
construction (same instrument, same session, same optics), so the simulated Δρ is a pure colocalization
contrast. Two different specimens share none of that: their difference would absorb every way the
specimens differ — biology, labelling, acquisition — and only partly colocalization. Scoring that against
a gate calibrated on the simulated Δρ would be **two arms measuring different quantities under one gate**,
the same defect class as the Δρ mislabelling itself.

So this plan does **not** compute a scored real-image Δρ. It records `real_delta_rho_computed = false` with
the reason, and the phase carries the named limit: *the amortized per-region Δρ map is validated on
simulation, where matched pairs exist by construction; on real data the phase demonstrates per-region
predictive calibration on two specimens, and no matched sample/control pair is available to validate Δρ
itself.* A specimen contrast between the two anchors MAY be reported as an illustrative figure, clearly
labelled as a specimen difference and explicitly **not** the Δρ the simulated arm scores, and it is not
scored against any threshold.

| quantity | n on real data | scored here? |
|---|---|---|
| leave-region-out predictive coverage (the SC3 criterion) | **2 images**, ~64 regions each | yes — reported, not gated (see below) |
| `region_rho_sample` / `region_rho_control` single-stack maps | 1 image each | reported |
| `region_delta_rho` (primary deliverable) | **not computable as a matched contrast** | **no** — named limit |

**THE EFFECTIVE INDEPENDENT n IS 2, NOT 128, AND THAT MUST BE STATED WHEREVER COVERAGE IS.** The 128
region-draws are **pseudo-replicates**: regions within an image share every nuisance and the global term,
so by 12-01's own pre-registered accounting the independent unit is the *dataset*. Record
`effective_independent_n = 2` as a mandatory key alongside `n_regions_scored = 128`, and require the
report to carry, in the same breath as every coverage figure, the sentence that **the 128 region-draws are
not 128 independent trials**. Compute any interval on the coverage estimate from the between-image spread
(n = 2) rather than from a binomial over 128 — and if that interval is too wide to be useful, say so,
because that is the honest consequence of having two images rather than a reason to use the wrong unit.

An earlier draft of this plan said "the effective sample is regions, and correlated ones". That was wrong
and is corrected here: it contradicted 12-01:172-178, and it is precisely the unit-mismatch this phase has
already had to fix twice.

**REAL DATA IS WHERE OOD STOPS BEING THEORETICAL.** Everything before this plan ran on the simulator's own
draws, so the summary was in-distribution by construction. These images were not generated by the forward
model. A region that is out of distribution produces a posterior the coverage number has no right to
count, so OOD screening is a precondition of scoring here rather than a diagnostic beside it. Follow the
`local_map.jl` discipline: an unscorable region carries the sentinel **and** a forced OOD flag, and a
missing operating point reads as NOT CHECKED rather than in-distribution.
