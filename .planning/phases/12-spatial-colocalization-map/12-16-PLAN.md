<objective>
Build the leave-region-out predictive machinery D-09 defines, calibrate its one modelling constant, and
measure the spatial-versus-ablation comparison on simulation — where ground truth still exists to check
that the machinery measures what it claims.

Purpose: D-09 replaced SC3's undefined "beats independent pooling in coverage" with something
well-defined and ground-truth-free, which is what makes it usable on a real image. But ground-truth-free
also means self-unchecked: if the construction is wrong, a real-image run cannot tell. Simulation is the
only place where the predictive interval can be compared against both the observed summary entry **and**
the drawn lattice value. Doing the simulated arm first, in this plan, is therefore not a rehearsal for
12-19 — it is the only validation the construction will ever get.
Output: the coverage library, the runner 12-19 reuses with `--real`, the simulated report, and the
Fisher-z Tier-2 append.

**PITFALL 6 IS A WORDING RULE WITH TEETH.** D-10's phrase "independent pooling has no mechanism to
predict a held-out region beyond the prior" is **false as written** and stating it in the report would be
a falsifiable overclaim. With r₁ → 0 the *regions* become conditionally independent, but the other 63
observed regions still inform the shared nuisances — especially `chromatic_eps`, whose radial gradient is
global — and the global term. The ablation's predictive is therefore the prior conditional on the shared
nuisances and the global term, which is strictly narrower than the marginal prior. Describe it as
**"no spatial borrowing, full nuisance and global borrowing"** everywhere, and report a third, genuinely
prior-only floor arm so a reader can see how much of the ablation's performance is nuisance/global
borrowing rather than spatial borrowing. The frozen SC3 amendment already commits the phase to this
wording (§4(c)), so a deviation here contradicts a committed document.

**PITFALL 5 IS WHY THE GATE IS TWO-SIDED.** The predictive interval for a held-out region's observed
correlation entry convolves posterior uncertainty about that region's ρ with per-region observation
noise, measured at **0.0662** in correlation units against an across-region spread of only 0.0847 at
constant ρ — a ratio of 1.28. If observation noise dominates, both arms show approximately nominal
coverage and "beats independent pooling in coverage" becomes a coin flip. Hence: **calibration** is a
qualifying condition required of both arms, and **sharpness given calibration** — a proper scoring rule —
is the discriminating one. `P12_STAGE2_LOGSCORE_MIN = 0.02` nats per held-out region is the pre-registered
bar, and a coverage-only win with no scoring-rule improvement is explicitly NOT a pass.

**Functions.**

`fisherz(r)` = `atanh(clamp(r, -0.999999, 0.999999))` and `inv_fisherz(z) = tanh(z)`. Comment the clamp:
`correlation()` can return exactly ±1 on a degenerate patch and `atanh(±1)` is infinite, so the clamp is a
guard, not a modelling choice — and a clamped entry must be counted and reported, because a silently
clamped region is a degenerate region.

`calibrate_neff(; imsize, n_draws, rng)` — the ONE calibration this file performs. Simulate pairs at a
**fixed** ρ field across many draws, compute the per-region `fisherz` of the observed correlation entries,
and solve for the single `n_eff` satisfying `Var(z) ≈ 1/(n_eff - 3)`. Return `n_eff` per image size in
`P12_IMSIZE_SET` plus the pooled value. Record in the comment why Fisher-z is preferred to an empirical
noise surface: it needs one calibrated constant rather than a two-dimensional surface in (image size,
|ρ|), it is the standard treatment, and it makes the |ρ| dependence automatic — research measured
0.0799 at ρ ≈ 0.16 against 0.0393 at ρ ≈ −0.82, which is exactly the `(1 − r²)` shape Fisher-z absorbs.

`predictive_draws(rho_draws, n_eff)` — step 5: map posterior ρ draws for the held-out region through
`fisherz`, add `randn * sqrt(1/(n_eff - 3))`, and map back with `inv_fisherz`. Returns predictive draws in
correlation units, the units the observed summary entry is in.

`lro_scores(observed, pred_draws; nominal = P12_COVERAGE_NOMINAL)` — steps 6a and 6b:
- `inside` — is `observed` within the equal-tailed `nominal` interval (reuse `_interval`, do not rewrite it)
- `logscore` — log predictive density of `observed` under the predictive draws, by a kernel density
  estimate with a stated bandwidth rule, **or** the closed-form Gaussian log density in Fisher-z space.
  Prefer the latter and say why: it has no bandwidth to tune, and a bandwidth is a free parameter that
  could be chosen to favour an arm. If the KDE form is used instead, the bandwidth rule must be a
  pre-registered constant.
- `crps` — reported alongside as a second proper scoring rule, since it is bounded and less sensitive to
  a single unlucky tail draw than log score.
Return a NamedTuple. Assert `length(pred_draws) >= 2`.

`lro_pass(spatial, ablation; nominal, tost_delta, logscore_min)` — the two-sided gate, as ONE function so
the rule cannot drift between the runner and the report:
1. Both arms must be calibrated: `|coverage - nominal| <= tost_delta`. A miscalibrated arm is
   **disqualified**, not "worse" — return `(:disqualified, which_arm)`.
2. Given both calibrated, require `mean_logscore(spatial) - mean_logscore(ablation) >= logscore_min`.
3. Return `(:pass | :fail | :disqualified, details)`. Document that a coverage-only win returns `:fail`.

`p12_coloc_map(bundle, mci, control_mci::Union{Nothing,MultiChannelImage}; N, nominal, n_eff)` — **the
read surface 12-12 deferred to this plan, and it takes a CONTROL (Δρ decision, 2026-07-28).** The
argument is positional and mandatory; `nothing` is the explicit single-stack mode specified below. TWO independent single-stack passes, mirroring
