<objective>
Decide, by measurement rather than preference, which lattice prior the phase uses and how many deviation
modes the production head carries.

Purpose (D-03, D-04): SC1 asks for the CAR-vs-GP comparison verbatim, and D-04 insists it run through a
deliberately HIGH-RANK head. The reason is a specific misreading this project has already paid for once:
a low-rank head bounds how rough a field it can represent, so a full-rank CAR field would be
systematically under-fit and the CAR arm would lose for a reason that has nothing to do with the prior —
a head artifact reported as a prior verdict, the same class of error that cost the Phase-7 SBC arm its
credibility. Running both arms through `K = P12_K_DEV = 63` (every non-constant DCT mode, so the head is
full-rank on the deviation space and cannot under-fit either arm by construction) makes the comparison
measure the prior.
Output: three trained mini-spike nets, one reported artifact, a verdict document, and the phase's first
Tier-2 append.
</objective>

**THE COMPARISON IS AT EQUAL r₁, AND THAT IS THE WHOLE POINT (R-8).** α and ℓ are not comparable knobs:

12-16. Do not build or pre-empt it here — using a predictive proxy where truth is available would be
strictly weaker evidence, and would make this plan depend on a model 12-16 has not yet calibrated.
Score in **Gaussian space** (R-2): the DCT coefficients of the Gaussian field are atom-free, whereas
ρ-space carries 6.79 % atom mass per region.

**THE SELECTION RULE, WRITTEN BEFORE ANY NUMBER EXISTS.** Put it in the header as prose and in the code
as one function `select_prior(scores)` so it cannot drift between the two:
1. An arm is **admissible** only if its Gaussian-space per-region coverage is within
   `P12_STAGE2_COVERAGE_TOST_DELTA` of `P12_COVERAGE_NOMINAL`. A miscalibrated arm is disqualified, not
   "better" — the same rule the SC3 amendment pre-declares for the coverage gate.
   **`select_prior` must assert `n_test >= P12_STAGE2_N_MIN` before applying that bound**, because the
   0.03 tolerance was derived in 12-01 for N ≥ 271 *datasets*; applying it at an unasserted n is the
   unit/power mismatch this phase has already corrected three times. If the mini-spike's test block is
   smaller, the run must stop and say so rather than quietly comparing against a bar built for a different
   n.
2. Among admissible arms, select the one with the lower pooled per-region RMSE against the drawn lattice.
3. Require the winner to beat the neutralized arm (`:none`, trained on `P12_ABLATION_R1`) on that RMSE by
   any margin; if it does not, record `SELECTED PRIOR: NONE-BEATS-ABLATION` and treat the spatial premise
   as unsupported at mini-spike scale — a reportable outcome that must be carried into the Stage-2
   verdict, not silently overwritten by picking a winner anyway.
4. Ties (RMSE within 1 %) resolve to **CAR**, declared here in advance, because it is lattice-native and
   sparse and therefore the cheaper production choice. Recording the tie-break in advance is what stops it
   becoming a post-hoc preference.

- `rmse_per_region` — Gaussian-space: reconstruct each posterior draw's field from its DCT coefficients

field ensemble, not of any net, so it answers "what rank is enough?" as arithmetic. Report the curve and
