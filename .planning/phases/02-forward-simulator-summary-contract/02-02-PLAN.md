Output is a 2-element `Vector{Matrix{Float64}}` that flows through the Wave-1 contract boundary unchanged, proving SIM-03 on real simulator output.

Stage primitives (RESEARCH §Architecture Patterns 1-4, all [ASSUMED] — verify against installed docstrings):
- correlated fields (SPIKE-VALIDATED shared-latent generator, D-15): draw a smooth latent field `L = imfilter(randn(rng, imsize), Kernel.gaussian(struct_σ))`, and per-channel independent fields `ε₁, ε₂` (same smoothing). Mix as `c1 = softplus(√|ρ|·L + √(1−|ρ|)·ε₁)`, `c2 = softplus(sgn(ρ)·√|ρ|·L + √(1−|ρ|)·ε₂)` (softplus = `log1p∘exp`, the nonneg transform). The channel-2 shared component is sign-flipped for negative ρ via `sgn(ρ)` so anti-correlation (negative induced μ) is reachable. This is NOT a Cholesky-over-randn nor a puncta/spot-mixture generator — those are rejected for the core (puncta saturates ~0.21 post-degrade and cannot go negative; D-15).
- PSF: `imfilter(ch, Kernel.gaussian(σ_psf))`, σ_psf fixed ≈1.0-1.5 px (D-05 discretion)
- spillover: directional `ch1' = ch1 + s*ch2` (2×2, NOT symmetric)
- sub-pixel shift: `warp(ch2, Translation(dx,dy), axes(ch2); fillvalue=0.0)` (one channel only)
- noise: `rand(rng, Poisson(gain*max(I,0)))/gain .+ rand(rng, Normal(0, read_noise), size(ch))`
