<objective>
Provide the draw and null-fitting machinery every Phase-14 runner shares, with the two silent-failure
modes closed by executable checks.

Purpose, and both are silent failures that produce plausible-looking numbers:

1. **Pitfall 1 — the calibration set must be π-distributed, NOT class-balanced.** The Phase-13 gate
   set is stratified to equal thirds (realized E 1334 / R 1333 / C 1333) while π at τ = 0.15 is
   E 0.3119 / R 0.4713 / C 0.2168. Split conformal's guarantee **requires the calibration points to
   be exchangeable with the test point**; a class-balanced calibration set against a π-distributed
   stream is not exchangeable, and the realized coverage misses `1−α` by an amount driven by the
   class-conditional score distributions. The code runs, the quantile computes, the number looks
   fine.

2. **Pitfall 4 — the shipped OOD null is on a DIFFERENT basis than the Phase-13 net.** The shipped
   bundle's `zt` standardizer is the Phase-7 one; the Phase-13 net rides **Phase 11's** `zt`,
   inherited and never re-fit. Scoring a Phase-11-standardized summary against a Phase-7-fitted
   Mahalanobis null produces a number with no interpretation.

Output: `spike/p14/pools.jl`, `spike/test/test_p14_pools.jl`.
