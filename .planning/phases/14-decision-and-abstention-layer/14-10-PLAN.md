<objective>
Check that the Bayesian-FDR rule does what it claims: that the **realized** false discovery proportion
among decided-and-accepted items tracks the rule's own **predicted** posterior-expected FDP, at four
pre-registered α levels; and report how sensitive that number is to the class prior.

**SC1-b (GATED):** on the shared `n_eval = 2000` unstratified evaluation set, for each
`α_FDR ∈ P14_ALPHA_FDR_GRID = (0.01, 0.05, 0.10, 0.20)`, the realized FDP must fall within the
binomial 95 % band of the rule's predicted `fdp`. Falsified if realized FDP exceeds the upper band at
any grid α.

**SC1-c (REPORTED, NOT GATED — no bar):** sweep `π_C` over
`P14_PI_COLOC_GRID = (0.05, 0.10, 0.217, 0.40, 0.70)` and report how `k*`, the realized FDP and the
decided fraction move. **Failing to report it is the failure.**

Output: `spike/p14/run_p14_fdr_check.jl` and `spike/p14/p14_fdr_report.jld2`.
</objective>

2. **The honest-claim block, written INTO the artifact** as string keys, so it travels with the
   numbers and cannot be dropped by a report writer:
   - `fdr_claim` — *the posterior expected false discovery proportion is controlled at α_FDR over the
     DECIDED subset only, the batch minus abstentions. It is not controlled over the whole batch: an
     abstained item is neither a discovery nor a non-discovery and appears in neither the numerator
     nor the denominator. The guarantee is conditional on the model (calibrated posteriors and a
     correct class prior) and is a posterior expectation, not a frequentist long-run rate.*
   - `assumption_a2_statement` — the two-line derivation: the rejection set `R` is a deterministic
     function of the observed data, hence σ(data)-measurable, hence pulls out of the conditional
     expectation, so a data-dependent pre-selection needs no selective-inference correction, unlike
     the frequentist case. **Stated as a derivation a referee can check in two lines, not asserted.**
   - `ordering_note` — abstain first, then sort; the reverse order can leave the residual accepted
     set's running mean ABOVE α, because removing items changes both numerator and denominator
     uncontrollably.
   - `independence_note` — `E[Σ 1{H₀ᵢ}] = Σ v_i` needs only linearity of expectation, **not**
     independence across the batch. The standard reviewer question, with a clean answer.
   - `prior_note` — `pi_class_masses` is the SIMULATOR prior's class mix, not any real batch's
     prevalence; a batch that is 90 % coloc makes every `v_i` too large and the rule too
     conservative, a batch that is 1 % coloc makes them too small and the FDR claim FALSE; the
     sensitivity table is the honest answer; empirical-Bayes estimation of π from the batch is
     deliberately not the default because it would make the guarantee circular.
   - `prior_atom_note` — the θ prior carries clamp atoms (~4.85 % of prior mass at ρ = −0.99 vs
     ~1.91 % at +0.99, a ~2.5:1 asymmetry against the exclusion end) which the measured
     `pi_class_masses` inherit and which enters the PRIOR term of the posterior directly, a term
     Phase 13 never used. Recorded as a stated property of the prior and as one more reason the
     π-sensitivity table is required.
   - `unit_note` — FDR is controlled **PER IMAGE PAIR** (D-04). Per-region/per-tile FDR is OUT OF
     SCOPE: `LocalColocMap` carries no uncertainty field, and Phase 12 returned NO on calibrated
     per-region uncertainty, so there is nothing to control against.
   - `amendment` — SC1 amended by D-02, SC2 amended by D-05; any report citing this result must cite
     the original ROADMAP wording alongside it.

3. Print a headline line, via `p14_headline` where a batch object exists, that contains BOTH the
   realized FDP and the decided fraction and the literal token `FDR SCOPE: DECIDED SUBSET ONLY`.
