<objective>
Compose the primitives into the entry point the phase is named for: `decide_coloc`, emitting
`{coloc / not / ABSTAIN}` at a user-set Bayesian FDR over a batch.

Purpose: this is where the ordering claim becomes code. **ABSTAIN FIRST, then FDR-sort the
survivors** — because the rejection set is a deterministic function of the observed data and
therefore σ(data)-measurable, so it pulls out of the conditional expectation for ANY data-dependent
selection; and because the reverse order leaves the residual accepted set with a running mean that
may EXCEED α. That derivation is **Assumption A2**, it is load-bearing, and the report must state it
rather than assert it.

**D-01, plainly:** the signature is `src/`-shaped — it takes a bundle plus images and returns an
`AbstractColocResult` subtype — so later promotion would be mechanical rather than a rewrite. **It is
built in `spike/` and is NOT shipped in v2.0.** This plan makes ZERO edits to `src/`.

Output: `spike/p14/decide.jl`, `spike/test/test_p14_decide.jl`.
</objective>
