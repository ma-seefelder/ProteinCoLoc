<ood_design>
<!-- 05-RESEARCH.md §OOD; Pitfall 2/7; D-03/D-04/D-05/D-06. -->
- Mahalanobis (recommended start): fit μ_S, Σ_S on the standardized TRAIN CONTINUOUS rows (1:64) ONLY — the 64 binary mask
  rows make Σ singular (Pitfall 2). score = (z[1:64]−μ_S)' Σ⁻¹ (z[1:64]−μ_S) via cholesky(Symmetric(Σ + 1e-6I)). Escalate to a
  NeuralEstimators NormalisingFlow log-lik ONLY if Mahalanobis AUC is weak (D-05 "pick by separability") — no new package (Pitfall 7).
- PP-mismatch: infer θ̂ via posterior_for(mean), re-simulate OOD_PP_REPS summaries via simulate_pair, discrepancy = Mahalanobis
  of S_obs vs the PP-summary cloud (default, D-05) — reaches some summary-orthogonal cases the density channel misses.
- Fusion: report each channel's own ROC + AUC; combined flag fires if EITHER exceeds its pre-registered ID-quantile threshold (OR).
- ROC/AUC: hand-roll from sorted scores (~15 lines, no new package). Operating point = OOD_ID_QUANTILE (committed before misspec
  data). Youden-J (max TPR−FPR) shown on the ROC as a labeled POST-HOC reference only — never the gate (D-06).
- Positive controls (D-03, 4 families, OOD_GRID_LEVELS magnitudes each): (1) texture (puncta/granular/fibrillar — a NEW spot/blob
  or fibre generator, NOT simulate_pair — the canonical real-world OOD Phase-2 rejected); (2) noise-model (non-Gaussian/salt-pepper/
  structured beyond Poisson+Gaussian); (3) optics/PSF (asymmetric/aberrated/out-of-focus/chromatic beyond σ_psf); (4) background/
  illumination (gradients/vignetting/autofluorescence bleed beyond U(0,0.1)/debris). All applied to FULLY EXTERNAL images (SC5).
- Negative control (D-04, the NAMED blind spot): correlation-preserving transforms on ID images — per-channel affine a·x+b (a>0),
  global rotation/flip, distribution-preserving block-permute. VERIFY empirically: KS test (ExactOneSampleKSTest / two-sample) on
  the 8×8 patch_summary distribution before vs after; assert statistic < OOD_KS_EPS. The flag MUST stay quiet on these by construction.
</ood_design>
