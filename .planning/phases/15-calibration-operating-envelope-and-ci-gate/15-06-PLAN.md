THE TYPE MISMATCH THAT MUST BE SHIMMED. `ProteinCoLoc.estimator_for(8)` returns an
`EstimatorBundle` struct with fields `(grid, npe, ratio, ood_nulls, zt, θzt, calibration)`
(src/registry.jl:59-67). The gate harness's `m` is what `load_gate_model(path)` =
`ProteinCoLoc.load_estimator(path)` returns: a NamedTuple `(estimator, θzt, zt, arch, meta)`
(src/amortized/persist.jl:101-102). The harness reads `m.estimator`, `m.zt`, `m.θzt`
(harness.jl:197-242). So the golden must shim
`(estimator = b.npe, θzt = b.θzt, zt = b.zt, arch = nothing, meta = nothing)`.
Use `estimator_for` rather than a bare path because it resolves in three integrity-checked steps —
the content-addressed artifact store, then the in-repo `artifacts/amended_v2/grid_8` dev dir WITH
tree-sha1 verification, then a lazy download of the v2.0.0 release asset (src/registry.jl:111-160) —
so it works locally and on a runner with no in-repo artifacts, and `julia-actions/cache@v3` caches
the download by default.

Golden bars frozen by plan 15-01 in test/gate/p15_consts.jl:
  P15_GOLDEN_M = SBC_FIX_M = 8 ; P15_GOLDEN_L = SBC_FIX_L = 15 ; P15_GOLDEN_BINS = SBC_FIX_BINS = 4
  P15_GOLDEN_IMSIZE = (256, 256)   # CONCRETE tuple -> gate_imsize scalar branch, consumes zero rng
  P15_GOLDEN_ECE_TOL = 1e-8 ; P15_GOLDEN_HONESTY (String)
`(SBC_FIX_L + 1) % SBC_FIX_BINS == 0` holds (16 % 4), so the rank-bin evenness assertion passes.
`sbc_gate` calls `seed_gate_global!(G)` internally via `sbc_ranks_and_spread`, so both halves of
reproducibility are pinned. Do NOT route the golden through `run_gate`: under
`SBC_REQUIRE_IMSIZE_PROVENANCE = true` it asserts the gate mixture against the net's training
provenance, and the golden deliberately uses one concrete size.

Two named fragilities to design around (research, §"The D-09 Golden"):
  1. `seed_gate_global!` calls `Random.seed!` on Julia's default task-local RNG, whose semantics have
     changed across Julia minors. A bit-exact ECE golden is therefore a JULIA-PATCH assertion, not a
     calibration assertion. Pin `version: '1.12.6'` and assert ECE with a tolerance.
  2. At M = 8 the ECE null mean is about 0.12, so the number carries no calibration information.
     State that in the script header.

The append-only guard recipe (CONVENTIONS C-03): gate on CHANGED DECLARATION lines only —
`git diff -U0 <base> -- test/gate/p15_consts.jl` filtered to lines matching a leading `+` or `-`
followed by optional whitespace and `const ` — and treat any surviving line starting with `-` as a
pre-registration breach. Context lines are not changes; `-U0` is what makes that true.

CI environment recipe: take it verbatim from `15-CI-BASELINE.md` (plan 15-02's measured,
observed-green apt list, Julia pin, instantiate step, xvfb prefix, and the cold/warm job durations).
Do not re-derive it.

Action versions verified this session: actions/checkout@v4, julia-actions/setup-julia@v3,
julia-actions/cache@v3. `@v3` is NEWER than the `@v2` most training data shows.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted PR contributor -> Actions runner | `pull_request` executes fork-authored repository content on a hosted runner |
| committed golden -> the claim "CI fails on calibration drift" | A control that can be silently re-blessed is a control that can be defeated |
| resolved model artifact -> the golden's meaning | If the net can be swapped without detection, the golden asserts nothing about the shipped tool |
