<objective>
Generate the lambda-hierarchical training pool and train the Phase-11 research net, then prove the
lambda conditioning is alive before any ladder run is permitted.

Purpose: the generative structure here is the single most important implementation detail in the
phase. If lambda were drawn independently of the shift, the network would correctly learn to ignore
the 129th input row and SC2 would fail flat for a reason that has nothing to do with resolution —
a null indistinguishable from "below resolution" but caused by a bug.

Output: `spike/data/p11_generate.jl`, `spike/npe/train_p11_npe.jl`, and the trained
`spike/npe/p11_research_npe.jld2`.
</objective>

The generative story the net must be trained against (RESEARCH §D13), in exactly this order:
```
for each training sample i:
    lambda_i   ~ Uniform(LAMBDA_MIN, LAMBDA_MAX)      # the UNCERTAINTY LEVEL — drawn FIRST
    shift_dx_i ~ Uniform(-lambda_i, +lambda_i)        # CONDITIONAL on lambda_i
    shift_dy_i ~ Uniform(-lambda_i, +lambda_i)
    eps_i      ~ Uniform(-0.02, +0.02)                # D-09: FIXED prior, NOT lambda-scaled
    rho_true_i = ghat(mu*_i),  mu*_i ~ MU_PRIOR       # unchanged
    (other 4 nuisances) ~ their existing priors       # unchanged
    theta_i    = (rho_true, spillover, autofl, label_eff, shift_dx, shift_dy, noise, chromatic_eps)
    imsize_i   ~ the F5 categorical
    y_i        = simulate_pair(rng_i, theta_i; imsize = imsize_i)
    Z_i        = vcat(standardize_summary(encode_d01(patch_summary(build_mci(y_i))), zt, :min),
                      encode_lambda(lambda_i))        # 129 rows
    train on (theta_i, Z_i)   # 8 theta rows; lambda is NOT a theta row
```

Reusable spike data machinery (`spike/data/`): `generate.jl` (`generate_samples`, the
Philox-per-index keyed loop), `cache.jl` (sharded atomic JLD2 with `shard_done` resume-by-skip),

`seeding.jl` (`Philox4x(UInt64, (seed xor SALT, idx))`). The theta-buffer width must be
