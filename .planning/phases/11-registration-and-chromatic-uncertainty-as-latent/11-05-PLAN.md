<objective>
Run the D-06 pre-flight probe — the cheapest risk control in the phase — and freeze the
probe-derived thresholds it supplies, before any training compute is spent.

Purpose: at grid 8 on small images each patch is about 32 px, so a 3 px misalignment is roughly a
9 percent displacement; after PSF blur the summary might barely move and SC2 would fail *flat* —
below resolution, not wrong design. The probe measures how far the 128-dimensional summary
actually moves relative to a known Delta-rho, in minutes, with no training. It supplies the SC2
threshold so that threshold is derived, not guessed.

Output: `spike/validation/run_p11_probe.jl`, its report artifact, and the appended Tier-2 block
of `spike/validation/p11_consts.jl`.
</objective>

   naming the reason (rows 65:128 are the near-constant present-mask and are exactly the rows
   `_summary_row_partition` excludes; including them dilutes the statistic). Report both the
   **mean** and the **median** 2-norm over replicates — the median because one degenerate patch
   mapped to 0 by `encode_d01` can move the norm by order 1.
4. **Arms.** Shift rungs `P11_PROBE_SHIFT_RUNGS` plus the extension `P11_PROBE_SHIFT_EXT`, injected
   along the diagonal (`dx = dy = magnitude / sqrt(2)`); chromatic rungs `P11_PROBE_EPS_RUNGS`
