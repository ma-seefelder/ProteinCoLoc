<objective>
Run the D-17 qualitative real-image check: inject a known misalignment into one channel of the
committed microscopy TIFFs, read the Delta-rho posterior width at each injected magnitude, and
compare the shape of that response against the simulated ladder.

Purpose: there is no ground-truth rho on real data, so this cannot be a coverage test. What it can
be is strong evidence that the simulator's degradation mechanism **transfers** — a matching width
response on real texture is exactly the transfer evidence D-17 is after, and a much smaller response
would say the simulator overstates how badly misalignment degrades patch correlation, which is worth
reporting either way.

Output: `spike/validation/run_p11_realimage.jl` and its report artifact.
</objective>

```julia
s = 1.0 / (1.0 + chromatic_eps)

ch2w = Matrix{Float64}(collect(warp(ch2, A, axes(ch2); method = BSpline(Linear()), fillvalue = FILL)))
```

Exactly one pass, not two.
