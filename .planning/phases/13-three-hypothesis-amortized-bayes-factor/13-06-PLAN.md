<objective>
Build the three-way evidence network: one shared trunk, two BCE heads, one forward pass.

Purpose: this is the architectural fork D-09 forced. `RatioEstimator` cannot express a three-way
head — its inference network always ends in a single output unit and its loss is hard-coded, so a
passed loss is **silently ignored** in v0.2.1. The route taken here is a new `NeuralEstimator`
subtype, which inherits NeuralEstimators' entire training loop (cosine-annealed LR, early stopping,
best-validation checkpointing, AdamW-Float64 handling) *and* honours a custom loss. That is what
makes D-10's claim — any difference from the shipped binary net is attributable to the head alone —
actually true.

Output: `spike/p13/net.jl` and `spike/test/test_p13_net.jl`. Training on real data is plan 13-11.
</objective>

**Binding rulings this plan implements (do not reopen):**
- **Route R1 is primary, R2 is the pre-declared fallback.** R1 = a `<: NeuralEstimator` subtype
  trained through NeuralEstimators' `train`. R2 = a hand-rolled Flux epoch loop, permitted ONLY if
  the A5 smoke test fails, and if used it must be recorded as a declared deviation because it
  weakens D-10's attribution argument. R3 (patching or forking `RatioEstimator`) is rejected.
- **No 3-class softmax.** A softmax head's logit differences are posterior-odds over three classes
  and would need a model prior over all three to convert to a Bayes factor — exactly what D-08
  refuses to invent.
- **The binary correction is not copied.** `amortized_log_bf`'s `- log_prior_odds` looks like the
  obvious template and is approximately zero in the shipped net, so a wrong copy would be invisible.
  The per-head term is a different quantity over a different denominator (Pitfall 1).
- **The input width is derived, never literal.** Phase 11 may deliver a conditioning vector of
  length other than 1. `pair_encode`'s `iseven` guard is the tripwire that catches the wrong
  lambda placement; do not weaken it.
- **This plan trains nothing on real data.** Its only training is the 200-sample, two-epoch smoke.

```julia
function build_ratio_estimator(input_dim::Integer; num_summaries = RATIO_NUM_SUMMARIES,
                               width = RATIO_SUMMARY_WIDTH)
    input_dim >= 1 || throw(ArgumentError("build_ratio_estimator: input_dim must be >= 1"))

end
```

```julia
struct ThreeWayEvidenceNet <: NeuralEstimator
    trunk; head
end
Flux.@layer ThreeWayEvidenceNet
(m::ThreeWayEvidenceNet)(Z) = m.head(m.trunk(Z))      # 2-by-n logits, ONE pass

function masked_two_head_bce(ŷ, y)          # ŷ :: 2-by-n logits, y :: 4-by-n targets
    lC = logitbinarycrossentropy.(view(ŷ,1,:), view(y,1,:); agg = identity)
    lE = logitbinarycrossentropy.(view(ŷ,2,:), view(y,3,:); agg = identity)
    wC = view(y,2,:); wE = view(y,4,:)
    return (sum(wC .* lC) + sum(wE .* lE)) / (sum(wC) + sum(wE) + eps(Float32))
end
```

```julia
function amortized_log_bf(est_bf, Z_pair, log_prior_odds; use_gpu::Bool = false)
    Zc   = Z_pair isa AbstractVector ? reshape(Z_pair, :, 1) : Z_pair
    grid = reshape(Float32[0.0 1.0], 1, 2)
    lr   = logratio(est_bf, Zc; grid = grid, use_gpu = use_gpu)
    return (lr[1, 2] - lr[1, 1]) - log_prior_odds        # <- DO NOT COPY THIS TERM
end
function pair_encode(Zs::AbstractVector, Zc::AbstractVector)
    length(Zs) == length(Zc) || throw(DimensionMismatch(...))
    iseven(length(Zs)) || throw(ArgumentError("pair_encode: summary length must be 2*G^2 (even)"))
    nc = length(Zs) ÷ 2
    d  = @view(Zs[1:nc]) .- @view(Zc[1:nc])
    return Float32.(vcat(Zs, Zc, d))
end
```
