**Binding rulings this plan implements (do not reopen):**
- **UNPAIRED, deliberately.** Phase 11's D-06 probe is paired because it measures displacement.
  This probe measures discriminability for a single unseen image, where the nuisances and the latent
  field are unknown. A paired design would report the resolution of a counterfactual the deployed
  tool never has and would understate tau by a large factor. This difference must be stated in the
  file itself, not only here.
- **Fit-free statistic.** `m-bar` is the canonical scalar readout of the summary with respect to rho
  — it is the same quantity the frozen `ghat` calibration was built on. A learned readout would be
  more powerful and would report a smaller tau, but would make tau a property of a trained model
  rather than of the summary, contradicting D-06. The NPE-based number may be reported as a
  secondary, model-dependent column only.
- **The probe STOPS at `encode_d01(patch_summary(...))`.** It never calls `standardize_summary`, so
  it needs no `zt` and no trained net (13-RESEARCH section E4). Do not add a `zt` argument.
- **No new dependency.** `roc_auc` is hand-rolled in this repo and `spike/test/runtests.jl` asserts
  `ROCAnalysis` and `MLJ` are absent. Reuse, never re-implement, never add.

function encode_d01(M::AbstractMatrix)
    vals = vec(coalesce.(M, 0.0))          # rows 1:64, missing -> 0
    mask = vec(Float64.(.!ismissing.(M)))  # rows 65:128, 1 = present

```julia
function roc_auc(neg_scores::AbstractVector, pos_scores::AbstractVector)
    P = length(pos_scores); N = length(neg_scores)
    (P == 0 || N == 0) && return (Float64[0.0, 1.0], Float64[0.0, 1.0], NaN)
    u = 0.0
    for p in pos_scores, n in neg_scores
        u += p > n ? 1.0 : (p == n ? 0.5 : 0.0)
    end
    return (fpr, tpr, u / (P * N))
end
```
