<objective>
Verify the D-07 three-way evidence-scale correction against an analytic ground truth, with two
negative controls, before a single image is simulated.

Purpose: D-07 explicitly forbids assuming the binary formula generalizes, and the research
established that it does not: the shipped binary net's `- log_prior_odds` is a redundancy under
NeuralEstimators' shuffled-theta construction, whereas the D-09 heads are plain BCE classifiers for
which the correction is genuinely required — and is exact only if stratification changed class
*frequencies* and never the *within-class* shape. That theorem is the single most consequential
piece of algebra in the phase, and it is cheap to test: a conjugate-Gaussian toy makes the true
three-way log Bayes factors analytic.

Output: `spike/p13/toy_gaussian.jl` and `spike/test/test_p13_correction.jl`.
</objective>

From 13-RESEARCH section F5 — the closed-form toy and its analytic evidence:
```
theta ~ N(0, s^2)                  # the "rho" analogue
Z | theta ~ N(theta, sigma^2)      # the "summary" analogue
classes: E = {theta < -tau}, R = {|theta| <= tau}, C = {theta > tau}
p(Z | class) = N(Z; 0, s^2+sigma^2) * [Phi((b-m)/sqrt(v)) - Phi((a-m)/sqrt(v))]
                                    / [Phi(b/s) - Phi(a/s)]
   with m = Z*s^2/(s^2+sigma^2), v = s^2*sigma^2/(s^2+sigma^2)
log BF(C:R) = log p(Z|C) - log p(Z|R)      # exact, for every Z
```

From 13-RESEARCH Code Example 4 — the runnable form:
```julia
import Distributions: Normal, cdf, logpdf
function log_evidence(Z, a, b; s, sigma)
    v = s^2*sigma^2/(s^2+sigma^2); m = Z*s^2/(s^2+sigma^2); sd = sqrt(v)
    num = cdf(Normal(m,sd), b) - cdf(Normal(m,sd), a)
    den = cdf(Normal(0,s),  b) - cdf(Normal(0,s),  a)
    return logpdf(Normal(0, sqrt(s^2+sigma^2)), Z) + log(num) - log(den)
end
analytic_log_bf_CR(Z; tau, s, sigma) = log_evidence(Z, tau, Inf; s, sigma) -
                                       log_evidence(Z, -tau, tau; s, sigma)
```

From 13-RESEARCH section F1 — the derivation being verified:
```
s_h(Z) = log[q(A|Z)/q(B|Z)] = log[p_q(Z|A)/p_q(Z|B)] + log(q_A/q_B)
=> log BF_q(A:B) = s_h(Z) - log(q_A/q_B)      with q_A, q_B measured on the head's OWN subset
```

From 13-RESEARCH section F2 — the theorem control 2 demonstrates: the scalar correction recovers
the pi-scale Bayes factor **iff** `q(theta|A) == pi(theta|A)` and `q(theta|B) == pi(theta|B)`; a
within-class distributional change enters inside the integral and depends on Z, so no scalar can
repair it.
