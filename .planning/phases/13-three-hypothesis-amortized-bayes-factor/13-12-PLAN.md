**Binding rulings this plan implements (do not reopen):**
- **Gate threshold-free, report argmax.** The gated statistics are per-class one-vs-random AUCs and
  the per-head ECE. The argmax confusion matrix is descriptive; the argmax rule can never declare
  random unless both log-BFs are negative, which is a *decision* rule, and decisions are Phase 14.
- **ECE gates, MCE does not.** Empty bins are scored as `|midpoint - 0.0|` with zero ECE weight and
  full MCE weight, so on a well-separated three-way problem MCE would fail for a reason unrelated to
  calibration. Report MCE beside its empty-bin count.
- **Every calibration number ships with its discrimination number.** A green ECE at an AUC near the
  base rate is a vacuous pass and must be labelled as such in the printed output and in the artifact.
- **Continuity is reported, never gated.** The shipped binary net trains on a different input surface
  (D-02) and its logit is a shuffled-theta likelihood-to-evidence ratio rather than a class-label
  BCE logit, so the two are not numerically interchangeable even at identical inputs.
- **Honest failure.** A shortfall is a Phase-13 finding for the report, never a reason to loosen a
  locked threshold, reseed, or re-run. The D-04 iteration allowance is reserved for the D-07-ii
  stratification switch and its trigger is named in the consts file.
- **No KDE, no quadgk.** The retired baseline is not reachable from the spike environment and this
  gate does not use it.

| Boundary | Description |
|----------|-------------|
| locked thresholds -> reported verdict | The gate is only meaningful if the numbers it scores against were committed before the net existed and are unchanged at run time |

| calibration statistic -> gate verdict | Gating on MCE would fail for an empty-bin artifact; gating on ECE alone would let a vacuous head pass |
