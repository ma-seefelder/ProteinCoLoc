<objective>
The DATA-03 leak-free loader: the single, sole standardization path that makes cross-fold leakage impossible by construction (D-07/D-08). `load_main_pool` reads the RAW (θ, summaries) shards; `load_fold` assigns deterministic k=5 folds from the master seed (D-09), fits a `StatsBase.ZScoreTransform` on the TRAIN columns ONLY and applies it to the held-out fold, passes the binary mask rows (65:128) through UNCHANGED, and returns Float32 d×K tensors plus the fit object so Phase 5 can freeze train-only preprocessing. There is NO exported global-standardize function — the footgun is removed structurally, not by convention. The reserved ≥20-stack ADVI holdout (D-10) lives in a separate file and is never in the main pool's `1:N` index range, so its exclusion from every fold is structural.

Purpose: This is the "leak-free split discipline baked into the loader structurally" half of the phase goal — the requirement that NPE metrics in Phase 4 are honestly cross-validated.
Output: `spike/data/loader.jl`, SC-3 (no global path, fit-on-train, mask bypass) + SC-4 (k-fold disjoint/complete, holdout excluded) tests.

HARD CONSTRAINT: all new files under `spike/`; reach `src/` ONLY via `contract.jl`'s read-only `include()`. Never edit `src/` or root manifests.
</objective>
