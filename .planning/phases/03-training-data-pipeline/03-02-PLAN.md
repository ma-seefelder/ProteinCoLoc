<objective>
The DATA-01 generation core: three spike-local modules that turn the calibrated prior + Phase-2 simulator + UNCHANGED summary contract into fixed-dimension training vectors in memory. `encode.jl` implements the locked 128-dim D-01 encoding (64 imputed correlation values + 64 present/absent mask) and the D-02 augmented-moment superset in one pass. `seeding.jl` provides Random123 `Philox4x` per-sample keyed RNGs (D-11) plus the disjoint-namespace salts and the D-03 per-sample `imsize` sampler. `generate.jl` composes them into an order-independent, thread-safe, serial-fallback generator core that emits column-major (θ, summary_min, summary_aug) matrices.

Purpose: This is the heart of DATA-01 and the reproducibility (D-11/D-12) + size-robustness (D-03) decisions. Persistence (sharding, hashing) is Wave 3; standardization is Wave 4. Here the cache is RAW and in-memory.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| θ/imsize → simulate_pair | The generator feeds prior-drawn parameters into the validated simulator; out-of-range values must surface, not corrupt downstream stages. No untrusted external input. |
| RNG keying → reproducibility | The per-sample key IS the integrity contract: a shared/mutable RNG under `@threads` would silently produce thread-count-dependent (non-reproducible) data. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
